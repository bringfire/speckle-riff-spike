# Speckle–Riff Spike

Public research and proof-of-concept workspace for connecting [Riff](https://github.com/bringfire/Riff) to Speckle's emerging Big Truck data model.

## Thesis

Speckle makes AEC project data durable, addressable, and versioned. Riff makes agent intentions inspectable, contestable, and authorizable before they become the next project version.

Reasoning is treated as a first-class project primitive: typed, immutable, grounded in project evidence, attributable to its producer, and linked to consequential human decisions.

## Initial proof

The first vertical slice will demonstrate:

```text
Grasshopper civic canopy — version A
→ Karamba produces preliminary deterministic analysis
→ Chirp agents reason over geometry, parameters, and analysis results
→ Riff presents grounded reasoning for human review
→ a human accepts, redirects, or stops the proposed action
→ the main agent performs only the authorized Grasshopper change
→ Grasshopper and Karamba recompute
→ Speckle records version B
→ Riff preserves the evidence → reasoning → decision → action → version lineage
```

Karamba results remain advisory. Agents do not replace simulation, deterministic calculation, professional engineering judgment, or licensed approval.

## Big Truck focus

The temporary proof may use Speckle's currently available connector as disposable demonstration transport. The enduring contracts target Big Truck's version-scoped artifact model, stable application identity, typed properties, topology, and selective machine-readable evidence.

This repository will document precisely what Big Truck enables for agentic AEC work beyond the temporary proof. It will not claim native Big Truck interoperability until verified against Speckle's actual implementation.

## Repository boundary

This repository contains only original Riff research, specifications, fixtures, and test harnesses. Local clones of Speckle repositories are ignored and remain governed by their respective upstream licenses. Private specifications, credentials, staging details, proprietary examples, and licensed binaries must never be committed here.

The Riff product remains in [bringfire/Riff](https://github.com/bringfire/Riff). This repository is an integration spike; successful, reviewed product work may later move into Riff.

## Status

Exploratory. No production compatibility claim is made.
